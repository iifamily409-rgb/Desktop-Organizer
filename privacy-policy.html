Privacy Policy

Desktop Organizer works on your files, so it should be obvious what it does with them and what it knows about you. Short answer: everything stays on your PC, and nothing is sold, uploaded or reported.

Applies to v1.0.1 Last updated 7 Nov 2026

Your files stay on your PC

Desktop Organizer reads, categorizes, moves and indexes the folders you explicitly allow it to watch. Those operations happen locally, on your machine, using a local engine that listens on 127.0.0.1 only.

  • No file content is uploaded to any server controlled by the project.
  • No remote backup, sync or “companion cloud” exists — there is no account to create.
  • File contents are not read into memory for analysis beyond size, hash, timestamps and extension, which is what duplicate detection and categorization need.
  • Removing the app leaves your files exactly where the app put them.

We do not sell user data

Desktop Organizer does not sell, rent, trade, broker or share personal data or file metadata with advertisers, data brokers or any third party. There is no such dataset to share.

What the app stores locally

All state lives in the app's data folder inside your Windows user profile:

  • Settings — watched folders, delays, conflict strategy, theme, startup and notification preferences.
  • Organization history — each run with the original and destination path for every file, which is what makes Undo possible.
  • Scan results — duplicate groups, large-file listings and the Downloads ignored list, until you rescan.
  • Logs — monitoring and error logs used for the in-app diagnostics view.
  • Assistant conversation — chat text you type and the replies you receive, kept locally if you use the assistant.

None of it leaves the machine, and all of it is deleted when you delete the app data folder. Uninstalling does not wipe your files or your library.

No hidden cloud uploads

The application makes no background network calls. It does not phone home for activation, licence checks or update pings; updates are something you download yourself from the GitHub release page.

The one exception is entirely user-initiated and visible: if you configure the AI assistant with a remote provider, requests to that provider go over the network. Everything else works fully offline.

AI settings and prompts

Assistant configuration — endpoint URL, model name, API key, permission level — is stored locally in your own app settings. Desktop Organizer has no server that receives those values.

  • The assistant is off until you configure a provider, and it keeps provider-neutral behaviour: your prompt goes only to the endpoint you entered.
  • Payloads contain the request text you typed plus the file names the action needs. File contents are not attached unless you explicitly include them.
  • Point the assistant at a local model server and no prompt leaves the machine at all.
  • Deleting or resetting the model settings on the assistant page clears what the app stored.

Third-party providers

If you choose an external provider, that provider's own privacy terms apply to the text you send it. Review them before pasting anything sensitive.

Telemetry

There is no telemetry. Desktop Organizer collects no usage analytics, crash reports, install counts or device identifiers, and it contains no analytics SDK.

Because of that there is also nothing to opt out of. If a future build ever adds optional diagnostics — for example a “share diagnostics with the maintainer” switch — this page will state it explicitly, and it will be off by default.

This website

The landing page is a static site hosted on GitHub Pages. It sets no cookies, contains no tracking scripts and runs no analytics.

  • The page loads its web fonts from the Google Fonts CDN, which means your IP address is visible to that service when the page renders — standard for any site using hosted fonts.
  • Installer downloads are served by GitHub's release asset storage, whose operator keeps ordinary server access logs.
  • Links to GitHub, the issue tracker and releases take you to pages governed by GitHub's own privacy policy.

Children's privacy

Desktop Organizer is a general-purpose utility for adults, collects no personal information from anyone, and is not directed at children under 13.

Changes and contact

Changes to this policy are published on this page with an updated “last updated” stamp, alongside the release that introduced them. Questions, corrections or requests about anything described here can be opened as an issue on GitHub or sent to the maintainer's GitHub profile.
