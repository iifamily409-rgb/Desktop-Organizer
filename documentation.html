How Desktop Organizer works

Everything you need to install the app, point it at the right folders and understand what it does to your files. Written for v1.0.1 on Windows 10 and Windows 11.

Version 1.0.1 Windows 10 / 11 · x64 Runs offline

Installation

Desktop Organizer ships as a single Windows installer: Desktop-Organizer-Setup-v1.0.1.exe (98.2 MB). It bundles the desktop shell and the local engine, so you do not need to install Python, Node or a database separately.

  1. Download the setup from the download section or the v1.0.1 release.
  2. Run the installer and choose the destination folder — the default per-user location needs no administrator rights.
  3. Finish the wizard. A desktop and Start Menu shortcut are created for you.

SmartScreen on first run

The build is not code-signed yet, so Windows may show “Windows protected your PC”. Choose More info → Run anyway. Full explanation in Known issues.

Requirements

  • Windows 10 or Windows 11, 64-bit.
  • Roughly 300 MB of disk space after installation.
  • No internet connection is needed to organize files.

Uninstall

Remove the app from Settings → Apps → Installed apps → Desktop Organizer, or run the uninstaller from the Start Menu folder. Your organized files and your library stay where you put them; the app does not delete user data on uninstall.

First start

On launch, Desktop Organizer opens the Dashboard, which summarises the last scans, the health score and the number of files handled in real time. The left sidebar gives you Files, Organizer, Search, Cleanup, Security, Assistant and Settings.

  1. Open Settings → Monitoring and switch on the folders you want watched. Desktop and Downloads are enabled by default; Documents, Pictures, Videos and Music are opt-in.
  2. Decide whether to keep files where they are or route them into one central library (Settings → Organization → Use one central library).
  3. Turn on Start with Windows if you want the monitor running in the background from login. Closing the window sends the app to the system tray, it does not stop monitoring.
  4. Run your first pass from Organizer → Organize now and review the preview before confirming the move.

Nothing moves without a preview

Every organizing run shows the planned source and destination for each file first, and each completed run is recorded in Organization History so you can undo it.

Desktop organization

The Desktop is one of the six monitor roots. When real-time monitoring is enabled, a new file on your desktop is held briefly while it finishes being written, then filed into a category folder based on its type.

Categories

Files are grouped into Documents, Images, Videos, Music, Archives, Code, Installers and Others. With the central library off, those folders are created next to the watched folder, so your desktop becomes Desktop\Images, Desktop\Documents and so on. With the library on, they are created inside OrganizerLibrary instead.

What is left alone

  • Shortcuts, folders and pinned items you created yourself.
  • Files that are still being written — see the stabilization delay under Settings.
  • Locked or in-use files; the monitor retries once they are released.

Undo

Open Organizer → History, pick the run and choose Undo moves. Individual batches can be reverted too, which is handy when one run swept up something you wanted to keep on the desktop.

Downloads organization

Downloads is the second root that ships enabled, and it is treated more carefully than any other folder because a half-finished download must never be moved.

In-progress files are protected

Desktop Organizer ignores installer scratch extensions (.crdownload, .partial, .part, .download, .opdownload, .tmp) and waits for a download completion delay after a file stops growing before it touches it. The dashboard counter Waiting to settle shows how many files are in that quiet period.

After completion

  1. Completed installers land in Installers, archives in Archives, documents and media in their own category.
  2. Cleanup → Downloads review lists stale or oversized leftovers you can move to the Recycle Bin, and an Ignored list keeps items you want to leave in place.
  3. Duplicate installers are flagged by the same content-based matcher used by the duplicate cleaner.

Duplicate cleaner

Open Cleanup to scan for duplicate files, large files and clutter. Duplicate detection compares file contents in chunks rather than trusting names or sizes, so two differently named copies of the same document are still matched.

Reviewing a group

  • Results are grouped so you can compare path, size and date, and sort by Size, Date or Name.
  • One copy in every group is kept by default — the cleaner never selects the whole group for you.
  • Confirming a removal moves the selected copies to the Recycle Bin, so the action is reversible until you empty it.

Duplicate safety

From v1.0.1 onward, deletion candidates are re-checked against the current file state before anything moves, so a group that changed while you were reviewing it is skipped instead of partially deleted.

Large files and hidden items

The same page reports large files above your configured size threshold and hidden items, with the disk totals for the scanned roots. Both use the Recycle Bin flow, never permanent deletion.

AI features

The assistant lives under Assistant and translates plain-language requests into file operations — “sort my downloads by type”, “find every PDF older than a year”. It is optional and provider-neutral: point it at an OpenAI-compatible endpoint or a local model server running on your machine.

Permission levels

Each action the assistant proposes is classified before it runs:

  • Read only — search and reporting; nothing changes.
  • Launches something — opens a file or folder.
  • Changes files — moves or renames items, always shown as a preview first.
  • Deletes files — requires explicit confirmation and routes to the Recycle Bin.

Keeping it local

Only the request text you send reaches the provider you configured; file contents are not attached unless you include them. With a local model server, nothing leaves the machine at all. Model settings can be reset at any time from the assistant page.

Settings

Everything that changes behaviour is in Settings, grouped by what it affects.

Monitoring

  • Auto-organize enabled — master switch for filing files automatically.
  • Enable real-time monitoring — watch roots with a live file-system listener.
  • Enable scheduled scan — periodic sweep on an interval (default 60 seconds, range 15–3600).
  • File stabilization delay — how long a file must stop changing before it is filed (default 2 seconds).
  • Download completion delay — extra quiet time after a file was seen growing (default 10 seconds).
  • Watched folders — the six known roots plus up to twelve custom folders.

Organization

  • Use one central library — route everything into one place instead of sorting in place.
  • Library location — where that library lives; OrganizerLibrary is created when you switch it on.
  • Existing file — conflict strategy when the destination already holds a match: rename (default) or skip.

Startup, notifications and appearance

  • Start with Windows — register the app at logon.
  • Organize on startup — run a full pass as soon as the app launches.
  • Windows notifications — toast messages for completed runs and warnings.
  • Theme — light, dark or follow Windows.

Diagnostics

The settings area also exposes the log viewer (filter by level, category or text) and a diagnostics snapshot with app, Python and engine versions plus the local API address — the useful first thing to check when something looks wrong.

Troubleshooting

The app says it cannot reach the engine

The interface talks to a local API over loopback. Restart the app from the tray (Quit Desktop Organizer, then launch again) and check the diagnostics snapshot in Settings. Nothing is sent over the network.

Files are not being organized

  1. Confirm Auto-organize enabled and Enable real-time monitoring are on.
  2. Check that the folder is actually a watched root, or add it as a custom watched folder.
  3. Look at Waiting to settle on the dashboard — files inside the stabilization window are intentionally untouched.
  4. Open the monitoring log in Settings and filter for the folder name.

A download broke or a file moved too early

Fixed in v1.0.1. If it still happens, raise the Download completion delay and make sure the browser's temporary extension is on the protected list. Undo the move from history and report it on the issue tracker.

Too many notifications

Turn off Windows notifications for repeat-only reporting, or disable Organize on startup if the burst happens at logon.

Nothing appears in the tray

Windows hides new tray icons by default. Open the overflow area (the chevron next to the clock) and drag the Desktop Organizer icon onto the visible bar; tray stability was hardened in v1.0.1.
