    Desktop Copilot

    Meet Desktop Copilot

    A ChatGPT-style assistant that already knows your folders. Mention a place with @, ask for what you want, and review the plan before a single file moves.

    • Context-aware prompts — @Desktop, @Downloads, @Documents scope the request to a watched folder.
    • Preview before action — every plan is labelled Read only, Launches something, Changes files or Deletes files.
    • Real chat workflow — sidebar, search, pinning, rename, archive, auto titles and export to TXT, Markdown, PDF or JSON.
    • Bring your own model — OpenRouter, OpenAI, Google AI Studio, Anthropic, LM Studio, Ollama or any custom endpoint.

    How it works

    From install to a clean desktop in four steps

    1. 01

      Install Desktop Organizer

      Run the Windows installer. The app, its services and the organizer engine are bundled — no extra runtime to set up.

    2. 02

      Select monitored folders

      Add Desktop, Downloads or any directory you want watched. Each folder keeps its own category rules.

    3. 03

      Enable auto organize

      Turn on real-time monitoring and new files are categorized within seconds — or run a one-time cleanup pass instead.

    4. 04

      Enjoy a clean workspace

      Everything is recorded in history, so any move, categorization or cleanup can be undone at any time.

    Trust

    Local first, and it stays that way

    Local firstThe engine runs on 127.0.0.1. Files, history and settings live in your user profile.
    Private by defaultNo account, no activation, no analytics SDK, no crash reporting, no device identifiers.
    Custom AI providersBring any OpenAI-compatible endpoint, or keep it fully local with LM Studio or Ollama.
    Windows nativeBuilt for Windows 10 and 11: tray, notifications, logon startup and a real uninstaller.
    No hidden uploadsNothing leaves your machine unless you ask the assistant something and configure a provider.
    No bundled API keysThe installer ships with zero credentials. Keys you add are stored locally, per profile.
