Use at your own risk

File-management software operates on live data. Bugs, interrupted power, disk errors, antivirus interference, unusual file names, symbolic links, oneDrive placeholders and network drives can all produce results nobody intends. The app is designed to be conservative — undo history, Recycle Bin instead of permanent deletion, protected download extensions — but it cannot make file operations risk-free.

Understand the undo window

Organization history restores moves the app performed. It does not restore files that a third party deleted afterwards, and it is not a replacement for versioning or backup.

Back up first

Before your first full pass on an important folder, take a copy. Realistic options:

  1. Run on a small test folder first, or use Organize now and read the preview without confirming.
  2. Keep a current File History, system image or cloud copy of anything you could not afford to recreate.
  3. Empty the Recycle Bin only after you are satisfied with a cleanup session.
  4. Watch the first few real-time runs from the dashboard so you learn what the app does with your specific file mix.
